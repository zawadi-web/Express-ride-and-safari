# Express Ride & Safaris Kenya

Official modern web application for **Express Ride & Safaris Kenya** — offering premium car hire & rentals, private airport transfers, curated safari experiences, and bespoke tours across Mombasa, Nairobi, and destinations throughout Kenya.

## Features

- **Automotive Fleet Showcase**: Responsive vehicle showcase with category filters (Economy, Saloon, SUV, Safari Vehicle) and realistic specifications (Seats, Gearbox, Fuel, Key Features).
- **Safari Expeditions**: Curated destination spotlights covering Maasai Mara, Amboseli, Tsavo, Diani Beach, Nairobi, and Mombasa with travel photography and key highlights.
- **Dedicated Airport Transfers**: Step-by-step visual journey (Airport → Pickup → Destination) covering JKIA, Wilson Airport, Moi International Mombasa, and SGR Terminus.
- **Instant WhatsApp Integration**: Direct click-to-chat links throughout every card, hero, and CTA pre-filled with specific vehicle or destination inquiries (+254748769876).
- **Mobile-First Experience**: Fully responsive with hamburger navigation and a fixed mobile contact bar (**CALL**, **WHATSAPP**, **BOOK**).
- **Interactive Quick Reservation Modal**: Quick lead submission and instant WhatsApp transfer.
- **Light Luxury White Theme with Animated Background**: Crisp, high-contrast typography, frosted glass card aesthetic, and an animated full-viewport background slideshow of Kenyan wildlife, coastlines, and open roads with smooth scroll parallax.
- **SEO & Social Sharing Optimized**: Semantic HTML5, Open Graph tags, descriptive meta tags, and custom branded SVG favicon.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Icons**: Custom lightweight SVG icon library

## Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 24)
- npm or yarn

### Installation

1. Clone repository:
   ```bash
   git clone https://github.com/zawadi-web/Express-ride-and-safari.git
   cd Express-ride-and-safari
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3050](http://localhost:3050) in your browser.

### Build for Production

```bash
npm run build
npm start
```
